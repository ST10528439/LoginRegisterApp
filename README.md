# LoginRegisterApp
LoginRegisterApp is Java a console app featuring secure user registration, South African phone validation, password complexity checks, payload hashing and JUnit 5 automated testing.it implements Login with welcome message and QuickChat menu with send message, store message, disregard message, view sent messages and quit option.
# Features
- User authentification
- Messaging engine
- Automated testing
# How to run the project
- Clone the repository
- Open in NetBeans IDE
- Execute application and then run files inside
- Execute Unit Tests
